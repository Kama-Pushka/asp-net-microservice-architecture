### Лабораторная работа №1

- [x] Написанное приложение для получения JSON с информацией о ip адресе.
Данные берем из API http://ip-api.com/json/.
В выводе указываем json {“myIP”: “IP_ADDRESS”}.
Затем подключаем другую апишку https://jsonip.com/.
Вывод должен быть такой же как и ранее.
    - ASP.NET API-приложение со сваггером, полученный IP записывается в БД (SQLite если локально, иначе СУБД определяется через env переменную). 
- [x] Выбор апи делается через переменные окружения например TYPE.
    - В [launchSettings.json](lab1/Properties/launchSettings.json)
